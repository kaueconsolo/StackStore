Simulador de Interface Ativo

Este produto possui um painel administrativo pronto com suporte a multi-inquilino (multi-tenant) e gateway Pix integrado.

Abrir Demonstrativo Completo 
// Exemplo da estrutura principal da API do App
import { StackStoreAuth, PaymentGateway } from '@stackstore/core';

export async function POST(req) {
  const session = await StackStoreAuth.verify(req);
  if (!session) return Response.json({ error: 'Unauthorized' }, { status: 401 });
  
  const payment = await PaymentGateway.createPixCharge({
    amount: req.body.amount,
    customer: session.user
  });

  return Response.json({ success: true, pixCode: payment.qrCode });
}
